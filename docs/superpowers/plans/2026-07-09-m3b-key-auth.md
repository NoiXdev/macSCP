# macSCP M3b — SSH-Key-Auth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Verbinden mit privaten SSH-Keys (OpenSSH ed25519, optional passphrase-verschlüsselt): Auth-Umschalter im Formular, Passphrase im Schlüsselbund, Key-Sessions in der Sidebar — plus zwei M3a-Backlog-Fixes.

**Architecture:** `SSHPrivateKeyLoader` (Core/SSH) lädt ed25519-Keys über Citadels OpenSSH-Parser und liefert die `SSHAuthenticationMethod`; typisierte `SSHKeyError` (nicht gefunden / Passphrase nötig / falsch / Format). `SSHConnectionConfig.AuthMethod` bekommt `.privateKey(keyPath:passphrase:)`, `CitadelFileSystem.connect` mappt darüber. `StoredSession` erhält `authKind .privateKey` + optionales `keyPath` (Codable-rückwärtskompatibel); das Session-Geheimnis im Schlüsselbund ist fortan „Passwort ODER Passphrase". `ConnectionViewModel` bekommt `authChoice`/`keyPath` (+ Field `.keyPath`), das Formular einen Picker (Passwort | SSH-Key) mit Key-Pfad-Feld (fileImporter) und Passphrase-SecureField (bindet an `password`). **Kein Schlüsselmaterial im Repo:** Tests erzeugen Keys zur Laufzeit via `ssh-keygen`; der Integrationstest installiert den Public Key per `docker exec` in den laufenden Testserver.

`Sources/macSCPCore/SSH/SSHPrivateKeyLoader.swift`:

```swift
import Citadel
import Crypto
import Foundation

public enum SSHKeyError: Error, Equatable, Sendable {
    case fileNotFound(path: String)
    case passphraseRequired
    case wrongPassphrase
    case unsupportedFormat(reason: String)
}

/// Lädt private OpenSSH-Keys (M3b: ed25519, optional verschlüsselt) über
/// Citadels Parser. RSA/ecdsa und ssh-agent sind bewusst verschoben.
public enum SSHPrivateKeyLoader {
    public static func authentication(
        username: String, keyPath: String, passphrase: String?
    ) throws -> SSHAuthenticationMethod {
        let expanded = NSString(string: keyPath).expandingTildeInPath
        guard FileManager.default.fileExists(atPath: expanded) else {
            throw SSHKeyError.fileNotFound(path: keyPath)
        }
        let contents: String
        do {
            contents = try String(contentsOfFile: expanded, encoding: .utf8)
        } catch {
            throw SSHKeyError.unsupportedFormat(reason: String(describing: error))
        }

        let decryptionKey = passphrase.flatMap { $0.isEmpty ? nil : Data($0.utf8) }
        do {
            let key = try Curve25519.Signing.PrivateKey(
                sshEd25519: contents, decryptionKey: decryptionKey)
            return .ed25519(username: username, privateKey: key)
        } catch {
            throw Self.map(error, hadPassphrase: decryptionKey != nil)
        }
    }

    private static func map(_ error: Error, hadPassphrase: Bool) -> SSHKeyError {
        let text = String(describing: error).lowercased()
        if text.contains("decrypt") || text.contains("passphrase")
            || text.contains("encrypted") || text.contains("cipher")
            || text.contains("padding") {
            return hadPassphrase ? .wrongPassphrase : .passphraseRequired
        }
        return .unsupportedFormat(reason: String(describing: error))
    }
}
```

**API-Drift-Behandlung (bewährtes M1/M2-Muster):** Vor dem Implementieren die tatsächlichen Citadel-APIs in `.build/checkouts/Citadel/Sources/Citadel/` verifizieren: der OpenSSH-Parser-Init (`Curve25519.Signing.PrivateKey(sshEd25519:decryptionKey:)` — exakte Parameter-Namen/Typen prüfen, evtl. `String`- und `Data`-Varianten) und `SSHAuthenticationMethod.ed25519(username:privateKey:)`. WICHTIG: Wenn Citadel TYPISIERTE Fehler wirft (z.B. ein OpenSSH-Error-Enum mit Fällen für falsche/fehlende Passphrase), diese im `map` gezielt matchen statt der String-Heuristik — die Heuristik ist nur der Fallback. Die 6 Tests definieren den Vertrag; nur die Aufrufstellen/das Mapping anpassen, nicht die Tests.

        let dir = URL(fileURLWithPath: NSTemporaryDirectory())
            .appendingPathComponent("macscp-itest-key-\(UUID().uuidString)")
        try FileManager.default.createDirectory(at: dir, withIntermediateDirectories: true)
        let keyURL = dir.appendingPathComponent("id_ed25519")

        let keygen = Process()
        keygen.executableURL = URL(fileURLWithPath: "/usr/bin/ssh-keygen")
        keygen.arguments = ["-t", "ed25519", "-f", keyURL.path(percentEncoded: false),
                            "-N", "", "-q", "-C", "macscp-itest"]
        try keygen.run()
        keygen.waitUntilExit()

        let pubKey = try String(contentsOfFile: keyURL.path(percentEncoded: false) + ".pub",
                                encoding: .utf8)
            .trimmingCharacters(in: .whitespacesAndNewlines)

        install.waitUntilExit()
