# macSCP M3b — SSH Key Auth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Connect with private SSH keys (OpenSSH ed25519, optionally passphrase-encrypted): auth switcher in the form, passphrase in the keychain, key sessions in the sidebar — plus two M3a backlog fixes.

**Architecture:** `SSHPrivateKeyLoader` (Core/SSH) loads ed25519 keys via Citadel's OpenSSH parser and delivers the `SSHAuthenticationMethod`; typed `SSHKeyError` (not found / passphrase required / wrong / format). `SSHConnectionConfig.AuthMethod` gets `.privateKey(keyPath:passphrase:)`, `CitadelFileSystem.connect` maps onto it. `StoredSession` gains `authKind .privateKey` + optional `keyPath` (Codable-backward-compatible); the session secret in the keychain is henceforth "password OR passphrase". `ConnectionViewModel` gets `authChoice`/`keyPath` (+ field `.keyPath`), the form a picker (Password | SSH key) with a key-path field (fileImporter) and a passphrase SecureField (binds to `password`). **No key material in the repo:** tests generate keys at runtime via `ssh-keygen`; the integration test installs the public key into the running test server via `docker exec`.

**Dependency graph (parallel phases for the coordinator):**

```
Task 0 ─→ [ Task 1 (KeyLoader) ∥ Task 3 (StoredSession v2) ] ─→ Task 2 (Config+Citadel)
        ─→ [ Task 4 (UI) ∥ Task 5 (key integration test) ] ─→ Task 6 (wrap-up)
```
(T1∥T3 and T4∥T5 are file-disjoint — worktrees.)

`Sources/macSCPCore/SSH/SSHPrivateKeyLoader.swift`:

```swift
import Citadel
import Crypto
import Foundation

public enum SSHKeyError: Error, Equatable, Sendable {
    case fileNotFound(path: String)
    case passphraseRequired
    case wrongPassphrase
    case unsupportedFormat(reason: String)
}

/// Loads private OpenSSH keys (M3b: ed25519, optionally encrypted) via
/// Citadel's parser. RSA/ecdsa and ssh-agent are deliberately deferred.
public enum SSHPrivateKeyLoader {
    public static func authentication(
        username: String, keyPath: String, passphrase: String?
    ) throws -> SSHAuthenticationMethod {
        let expanded = NSString(string: keyPath).expandingTildeInPath
        guard FileManager.default.fileExists(atPath: expanded) else {
            throw SSHKeyError.fileNotFound(path: keyPath)
        }
        let contents: String
        do {
            contents = try String(contentsOfFile: expanded, encoding: .utf8)
        } catch {
            throw SSHKeyError.unsupportedFormat(reason: String(describing: error))
        }

        let decryptionKey = passphrase.flatMap { $0.isEmpty ? nil : Data($0.utf8) }
        do {
            let key = try Curve25519.Signing.PrivateKey(
                sshEd25519: contents, decryptionKey: decryptionKey)
            return .ed25519(username: username, privateKey: key)
        } catch {
            throw Self.map(error, hadPassphrase: decryptionKey != nil)
        }
    }

    private static func map(_ error: Error, hadPassphrase: Bool) -> SSHKeyError {
        let text = String(describing: error).lowercased()
        if text.contains("decrypt") || text.contains("passphrase")
            || text.contains("encrypted") || text.contains("cipher")
            || text.contains("padding") {
            return hadPassphrase ? .wrongPassphrase : .passphraseRequired
        }
        return .unsupportedFormat(reason: String(describing: error))
    }
}
```

**API drift handling (proven M1/M2 pattern):** Before implementing, verify the actual Citadel APIs in `.build/checkouts/Citadel/Sources/Citadel/`: the OpenSSH parser init (`Curve25519.Signing.PrivateKey(sshEd25519:decryptionKey:)` — check the exact parameter names/types, possibly `String` and `Data` variants) and `SSHAuthenticationMethod.ed25519(username:privateKey:)`. IMPORTANT: if Citadel throws TYPED errors (e.g. an OpenSSH error enum with cases for wrong/missing passphrase), match those specifically in `map` instead of the string heuristic — the heuristic is only the fallback. The 6 tests define the contract; adjust only the call sites/the mapping, not the tests.
