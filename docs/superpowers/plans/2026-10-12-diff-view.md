# Diff View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Compare two files, or two folders recursively, between the local and
the remote side of one session — showing which paths differ and the content
diff of any text pair.

**Architecture:** Three pure Core pieces (pairing, classification, line diff)
under `Sources/macSCPCore/Compare/`, a comparison model owned by the
`SessionTab` that owns the connection, and a third SwiftUI scene that is only
a view onto that model, resolved through `TabRegistry.tab(for:)`. Remote
content reaches local temp files through the existing transfer queue, never
through a new download path.

**Tech Stack:** Swift 6 (`.swiftLanguageMode(.v6)`), SwiftPM, SwiftUI,
Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-12-diff-view-design.md`

## Review Focus

Five input classes the spec implies, that no task's own happy path exercises,
most likely to bite first:

1. **A name that differs only by Unicode normalization.** macOS stores local
   names decomposed (NFD); SFTP and S3 hand back whatever the server stored,
   usually composed (NFC). `ä` as one scalar and as `a` + U+0308 are the same
   file to a person and two different relative paths to a dictionary — so a
   mirrored folder would report every such file as `onlyLeft` AND
   `onlyRight`. Pinned in Task 1.
2. **A listing with no size.** `RemoteFileItem.size` is `UInt64?`. "Size
   decides first" must not read a missing size as a match; a pair where
   either side has no size goes to the checksum, and if that is unavailable
   it is `undetermined`. Pinned in Task 2.
3. **A symlink on one side.** `RemoteFileKind` has `.symlink` and `.other`
   beside `.file` and `.directory`, and neither a content diff nor a
   recursive descent is meaningful for them. Pinned in Task 2.
4. **Two remote names that collide on a case-insensitive local side.**
   `README` and `readme` both exist remotely; locally they are one path. The
   pairing must not silently drop one. Pinned in Task 1.
5. **A cancel during the walk.** A recursive comparison over a network is the
   one operation here a user will want to stop, and a cancel that only hides
   the progress line while the walk keeps listing is the failure that looks
   like success. Pinned in Task 3.

```swift
import Foundation

/// One relative name seen on one or both sides of a comparison.
///
/// `name` is the name as it will be SHOWN, taken from the left side when it
/// exists and from the right otherwise — the pairing key is a normalized
/// form, which is not what a person should read.
public struct ComparisonPair: Equatable, Sendable {
    public let name: String
    public let left: RemoteFileItem?
    public let right: RemoteFileItem?

    public init(name: String, left: RemoteFileItem?, right: RemoteFileItem?) {
        self.name = name
        self.left = left
        self.right = right
    }
}

public enum ComparisonPairing {
    public static func pairs(
        left: [RemoteFileItem], right: [RemoteFileItem]
    ) -> [ComparisonPair] {
        let exact = pairUniquely(left: left, right: right) { Array($0.name.utf8) }
        let normalized = pairUniquely(
            left: exact.unpairedLeft, right: exact.unpairedRight
        ) { $0.name.precomposedStringWithCanonicalMapping }

        let all = exact.pairs + normalized.pairs
            + normalized.unpairedLeft.map { ComparisonPair(name: $0.name, left: $0, right: nil) }
            + normalized.unpairedRight.map { ComparisonPair(name: $0.name, left: nil, right: $0) }
        return all.sorted(by: ordering)
    }

    /// Pairs the items whose key is carried by exactly one item on each side.
    /// Every other item comes back as unpaired.
    private static func pairUniquely<K: Hashable>(
        left: [RemoteFileItem], right: [RemoteFileItem],
        key: (RemoteFileItem) -> K
    ) -> (pairs: [ComparisonPair], unpairedLeft: [RemoteFileItem], unpairedRight: [RemoteFileItem]) {
        let leftByKey = Dictionary(grouping: left, by: key)
        let rightByKey = Dictionary(grouping: right, by: key)

        var pairByKey: [K: ComparisonPair] = [:]
        for (k, lefts) in leftByKey {
            guard lefts.count == 1, let rights = rightByKey[k], rights.count == 1 else { continue }
            pairByKey[k] = ComparisonPair(name: lefts[0].name, left: lefts[0], right: rights[0])
        }

        return (
            pairs: Array(pairByKey.values),
            unpairedLeft: left.filter { pairByKey[key($0)] == nil },
            unpairedRight: right.filter { pairByKey[key($0)] == nil }
        )
    }

    private static func ordering(_ lhs: ComparisonPair, _ rhs: ComparisonPair) -> Bool {
        let lhsNFC = lhs.name.precomposedStringWithCanonicalMapping
        let rhsNFC = rhs.name.precomposedStringWithCanonicalMapping
        if lhsNFC != rhsNFC { return lhsNFC < rhsNFC }
        return lhs.name.utf8.lexicographicallyPrecedes(rhs.name.utf8)
    }
}
```

**Corrected 2026-10-12, after the task shipped**, and the code above is read
back off `Sources/macSCPCore/Compare/ComparisonPair.swift` at `40bb75ae`
rather than retyped. **The single-pass implementation that stood here is
withdrawn as defective.** Its doc comment read: "Pairs two listings by name.
The key is `precomposedStringWithCanonicalMapping` — NFC — because a local
listing on macOS hands back NFD and a server usually stored NFC, and the same
file must not appear as two rows", and its body wrote each item into
`byKey[key]?.left = item` / `byKey[key]?.right = item`.

Two faults, the first found by the implementer and the second by the ruling
that answered it:

1. **Within ONE side, two names sharing an NFC key overwrote each other.** A
   directory on a byte-based filesystem can hold both `ä` (U+00E4) and
   `a` + U+0308 as two distinct files; the second overwrote the first and one
   file vanished from the comparison with no trace. That is the same failure
   the case-folding sentence above was written to prevent, committed one line
   away from it.
2. **"Pair exact names first" cannot be written with a `String` key.** Swift's
   `String` equality IS Unicode canonical equivalence, so a `String`-keyed
   first pass merges the two spellings again and restores fault 1. The key
   must be `Array(name.utf8)`. This correction is owed to the implementer,
   not to the ruling, which said only "identical as raw bytes".

The tests for both are in `ComparisonPairingTests`, and each ambiguity test
pins its own premise — one NFC form, pairwise distinct UTF-8 bytes — so it
cannot pass for the wrong reason.

```swift
import Foundation

/// Why a pair could not be settled. Carried in the state rather than shown
/// in a note above the table: a row that says "same" when nothing measured
/// it is the defect this type exists to prevent.
public enum UndeterminedReason: Equatable, Sendable {
    /// Neither side could produce a checksum. An SSH far side with no
    /// checksum tool answers this; so does every WebDAV connection; and so
    /// does a backend that is not a `RemoteChecksumProvider` at all.
    case checksumUnavailable
    /// The connection can hash, but not with the algorithm that was asked
    /// for. A different reason from the one above, and a different remedy:
    /// the user can change `SettingsStore.checksumAlgorithm`.
    case algorithmUnavailable(ChecksumAlgorithm)
    /// The two sides answered with DIFFERENT algorithms, so their hexes say
    /// nothing about each other.
    case algorithmsDiffer
    /// One side's value is an object store's multipart ETag, which is an
    /// MD5 over the parts' MD5s and not a hash of the file's bytes at all.
    /// Comparing it to anything would be meaningless.
    case etagIsNotAFileHash
    /// A symlink or an `other` entry: no content comparison is meaningful.
    case unsupportedKind
}

public enum ComparisonState: Equatable, Sendable {
    case onlyLeft
    case onlyRight
    case same
    case differs
    case typeMismatch
    case undetermined(UndeterminedReason)
}

public enum ComparisonClassification {
    /// Classifies one pair.
    ///
    /// Order matters and is the cheap half of the design: a size difference
    /// settles the pair with no checksum at all. A checksum is asked for
    /// only where the sizes are EQUAL AND KNOWN — a `nil` size says the
    /// listing could not tell us, which is not the same as a match, so it
    /// falls through to the checksum rather than settling anything.
    public static func state(
        for pair: ComparisonPair,
        leftChecksum: @Sendable () async throws -> RemoteChecksumOutcome,
        rightChecksum: @Sendable () async throws -> RemoteChecksumOutcome
    ) async throws -> ComparisonState {
        guard let left = pair.left else { return .onlyRight }
        guard let right = pair.right else { return .onlyLeft }

        if left.kind != right.kind { return .typeMismatch }
        if left.kind == .symlink || left.kind == .other {
            return .undetermined(.unsupportedKind)
        }
        if left.kind == .directory { return .same }

        if let l = left.size, let r = right.size, l != r { return .differs }

        let a: FileChecksum
        switch try await leftChecksum() {
        case .checksum(let value): a = value
        case .unavailableOnThisConnection: return .undetermined(.checksumUnavailable)
        case .algorithmUnavailable(let algorithm):
            return .undetermined(.algorithmUnavailable(algorithm))
        }

        let b: FileChecksum
        switch try await rightChecksum() {
        case .checksum(let value): b = value
        case .unavailableOnThisConnection: return .undetermined(.checksumUnavailable)
        case .algorithmUnavailable(let algorithm):
            return .undetermined(.algorithmUnavailable(algorithm))
        }

        // A multipart ETag is "an MD5 over the parts' MD5s. Not the file's
        // hash, whatever it looks like" — `ChecksumProvenance`'s own words.
        // Two identical files can carry different multipart ETags (different
        // part sizes) and two different files could in principle carry the
        // same one, so this value settles nothing in either direction.
        if case .objectStorageETagMultipart = a.provenance {
            return .undetermined(.etagIsNotAFileHash)
        }
        if case .objectStorageETagMultipart = b.provenance {
            return .undetermined(.etagIsNotAFileHash)
        }

        // Two hexes from different algorithms say nothing about each other.
        // An S3 side answers with `.md5` from its ETag while a local side
        // computes the user's chosen algorithm, so this is the ordinary
        // case for a local↔S3 pair, not a corner.
        guard a.algorithm == b.algorithm else {
            return .undetermined(.algorithmsDiffer)
        }

        return a.hex == b.hex ? .same : .differs
    }
}
```

```swift
import Foundation

public struct ComparisonRow: Equatable, Sendable {
    public let relativePath: String
    public let state: ComparisonState
}

public struct ComparisonProgress: Equatable, Sendable {
    public let directoriesVisited: Int
    public let rowsProduced: Int
}

public enum FolderComparison {
    /// Walks both sides breadth-first, pairing each directory level and
    /// classifying every pair.
    ///
    /// `Task.checkCancellation()` is called before each directory is listed,
    /// so a cancel stops the network work rather than only the reporting —
    /// a walk that keeps listing after a cancel costs the user the thing
    /// they asked to stop paying.
    ///
    /// A directory present on one side only produces ONE row and is not
    /// descended into: naming every file under it would bury the fact that
    /// the whole directory is missing.
    public static func walk(
        left: any RemoteFileSystem, leftRoot: String,
        right: any RemoteFileSystem, rightRoot: String,
        algorithm: ChecksumAlgorithm,
        onRow: (ComparisonRow) -> Void,
        onProgress: (ComparisonProgress) -> Void
    ) async throws {
        var queue: [String] = [""]
        var directoriesVisited = 0
        var rowsProduced = 0

        while !queue.isEmpty {
            try Task.checkCancellation()
            let relative = queue.removeFirst()
            let leftPath = join(leftRoot, relative)
            let rightPath = join(rightRoot, relative)

            let leftItems = try await left.list(path: leftPath)
            let rightItems = try await right.list(path: rightPath)
            directoriesVisited += 1

            for pair in ComparisonPairing.pairs(left: leftItems, right: rightItems) {
                try Task.checkCancellation()
                let childRelative = relative.isEmpty ? pair.name : relative + "/" + pair.name
                let state = try await ComparisonClassification.state(
                    for: pair,
                    leftChecksum: { [left] in
                        try await Self.checksum(of: pair.left, on: left, algorithm: algorithm)
                    },
                    rightChecksum: { [right] in
                        try await Self.checksum(of: pair.right, on: right, algorithm: algorithm)
                    })

                if state == .same, pair.left?.kind == .directory {
                    queue.append(childRelative)
                    continue
                }
                onRow(ComparisonRow(relativePath: childRelative, state: state))
                rowsProduced += 1
            }

            onProgress(ComparisonProgress(
                directoriesVisited: directoriesVisited, rowsProduced: rowsProduced))
        }
    }

    private static func join(_ root: String, _ relative: String) -> String {
        relative.isEmpty ? root : root + "/" + relative
    }

    /// `RemoteFileSystem` does NOT inherit `RemoteChecksumProvider` — it is
    /// declared `public protocol RemoteFileSystem: Sendable`, and the
    /// checksum lives on its own protocol. This is the conditional cast
    /// `RemoteBrowserViewModel.checksum(of:algorithm:)` already uses, with
    /// the same answer when it fails: a backend that cannot be asked is a
    /// backend that answered "not on this connection".
    private static func checksum(
        of item: RemoteFileItem?, on fs: any RemoteFileSystem,
        algorithm: ChecksumAlgorithm
    ) async throws -> RemoteChecksumOutcome {
        guard let item, item.kind == .file else { return .unavailableOnThisConnection }
        guard let provider = fs as? any RemoteChecksumProvider else {
            return .unavailableOnThisConnection
        }
        return try await provider.remoteChecksum(forFileAt: item.path, algorithm: algorithm)
    }
}
```

**A concurrency note, resolved here rather than left to be discovered.**
Under `.swiftLanguageMode(.v6)` the two callbacks above are called across
`await` boundaries, which is exactly where strict concurrency objects. Two
shapes work and one does not:

- **Works:** mark `walk` `@MainActor` and keep the plain closures. The caller
  in Task 7 is a `@MainActor` model and the callbacks drive observable state,
  so this is where they belong — the network `await`s suspend, they do not
  move the work off the actor.
- **Works:** make `walk` nonisolated and both callbacks `@Sendable`, with the
  caller hopping to the main actor itself.
- **Does not:** nonisolated `walk` with non-`Sendable` closures. If the build
  rejects the first shape, take the second; do not silence the diagnostic
  with `@preconcurrency` or an unchecked conformance.

Take the first shape. If a measurement later shows the walk starving the main
actor, that is a backlog row with the measurement attached, not a reason to
reach for the second shape blind.

```swift
public struct DiffLine: Equatable, Sendable {
    public enum Kind: Equatable, Sendable { case context, added, removed }
    public let kind: Kind
    public let text: String
}

public struct DiffHunk: Equatable, Sendable {
    public let leftStart: Int
    public let rightStart: Int
    public let lines: [DiffLine]
}

public enum FileDiff {
    /// A line diff over two already-local files, as line arrays.
    ///
    /// Pure: no file system, no connection, no UI. Everything expensive
    /// about comparing two files happened before this was called, which is
    /// why the size ceiling lives in `DiffEligibility` and not here.
    public static func hunks(
        left: [String], right: [String], context: Int
    ) -> [DiffHunk] {
        let script = editScript(left: left, right: right)
        return group(script, context: context)
    }

    /// One entry per output line, carrying the index it came from on each
    /// side so `group` can compute a hunk's start without a second pass.
    private struct Step {
        let line: DiffLine
        let leftIndex: Int
        let rightIndex: Int
    }

    private static func editScript(left: [String], right: [String]) -> [Step] {
        // Classic LCS length table. Rows are left, columns are right.
        var table = [[Int]](
            repeating: [Int](repeating: 0, count: right.count + 1),
            count: left.count + 1)
        if !left.isEmpty && !right.isEmpty {
            for i in stride(from: left.count - 1, through: 0, by: -1) {
                for j in stride(from: right.count - 1, through: 0, by: -1) {
                    table[i][j] = left[i] == right[j]
                        ? table[i + 1][j + 1] + 1
                        : max(table[i + 1][j], table[i][j + 1])
                }
            }
        }

        var steps: [Step] = []
        var i = 0, j = 0
        while i < left.count && j < right.count {
            if left[i] == right[j] {
                steps.append(Step(
                    line: DiffLine(kind: .context, text: left[i]),
                    leftIndex: i, rightIndex: j))
                i += 1; j += 1
            } else if table[i + 1][j] >= table[i][j + 1] {
                steps.append(Step(
                    line: DiffLine(kind: .removed, text: left[i]),
                    leftIndex: i, rightIndex: j))
                i += 1
            } else {
                steps.append(Step(
                    line: DiffLine(kind: .added, text: right[j]),
                    leftIndex: i, rightIndex: j))
                j += 1
            }
        }
        while i < left.count {
            steps.append(Step(
                line: DiffLine(kind: .removed, text: left[i]),
                leftIndex: i, rightIndex: j))
            i += 1
        }
        while j < right.count {
            steps.append(Step(
                line: DiffLine(kind: .added, text: right[j]),
                leftIndex: i, rightIndex: j))
            j += 1
        }
        return steps
    }

    /// Groups the script into hunks. A run of more than `2 * context`
    /// unchanged lines separates two hunks; a shorter run stays inside one,
    /// because splitting there would show the same lines twice.
    private static func group(_ steps: [Step], context: Int) -> [DiffHunk] {
        let changed = steps.indices.filter { steps[$0].line.kind != .context }
        guard !changed.isEmpty else { return [] }

        var ranges: [(start: Int, end: Int)] = []
        for index in changed {
            let start = max(0, index - context)
            let end = min(steps.count - 1, index + context)
            if var last = ranges.last, last.end >= start - 1 {
                last.end = max(last.end, end)
                ranges[ranges.count - 1] = last
            } else {
                ranges.append((start, end))
            }
        }

        return ranges.map { range in
            let slice = Array(steps[range.start...range.end])
            return DiffHunk(
                leftStart: slice[0].leftIndex,
                rightStart: slice[0].rightIndex,
                lines: slice.map(\.line))
        }
    }
}
```

Note for the implementer: the table is `(left.count + 1) × (right.count + 1)`
`Int`s, so its memory is the product of the two line counts — which is the
cost `DiffEligibility.ceilingBytes` exists to bound, and the quantity Task 6
measures. Do not raise that ceiling without the measurement.

```swift
import Foundation

public enum DiffRefusal: Equatable, Sendable {
    case binary
    case tooLarge(bytes: Int, ceiling: Int)
}

public enum DiffEligibility {
    /// 4 MiB per side.
    ///
    /// **A STARTING VALUE, NOT A MEASUREMENT.** Nothing in this tree set a
    /// precedent for it, and a line diff's cost is dominated by the number
    /// of DIFFERENCES rather than by the file size, so this number is
    /// expected to move once the plan's own measurement exists. Until then,
    /// no comment, document or catalogue text here describes it as measured.
    public static let ceilingBytes = 4 * 1024 * 1024

    /// Why this content cannot be shown as a line diff, or `nil` when it can.
    ///
    /// The NUL test reads the first 8000 bytes, which is git's own
    /// heuristic, adopted by name rather than invented.
    public static func refusal(forBytes bytes: [UInt8]) -> DiffRefusal? {
        if bytes.count > ceilingBytes {
            return .tooLarge(bytes: bytes.count, ceiling: ceilingBytes)
        }
        if bytes.prefix(8000).contains(0x00) { return .binary }
        if String(bytes: bytes, encoding: .utf8) == nil { return .binary }
        return nil
    }
}
```
