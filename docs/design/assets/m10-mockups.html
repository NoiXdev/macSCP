Dreiweg pro Login-Stelle (Ziel-Host UND Jump-Host): (A) Login-Set wählen — der Picker listet alle Sets, daneben „Logins verwalten…". (B) Manuell — Benutzername + Passwort/Key direkt an der Verbindung, wie heute; Daten bleiben verbindungs-lokal. (B+) Im Manuell-Modus optional der Toggle „Als neues Login-Set speichern" mit Namensfeld — beim Verbinden/Speichern entsteht das Set und die Verbindung referenziert es sofort. Der Umschalter merkt sich je Verbindung seinen Modus; „Bearbeiten…" einer Session zeigt den jeweiligen Zustand.
Set-Modell: Ein Login-Set = Name + Benutzername + Auth (Passwort im Keychain ODER Key-Pfad + optionale Passphrase). Verbindungen können ein Set referenzieren statt eigener Zugangsdaten — Passwort ändern heißt dann: einmal im Set ändern, gilt überall. Gleichheits-Erkennung: beim Öffnen des Logins-Bereichs (und nach Imports) werden bestehende Verbindungen mit identischem (user + Auth-Art + Key-Pfad bzw. identischem Keychain-Passwort) gruppiert; der Banner schlägt das Zusammenfassen vor — „Zusammenfassen…" zeigt vorher die betroffenen Verbindungen und legt dann EIN Set an, auf das alle umgestellt werden (rückgängig-freundlich: die Sessions behalten funktionierende Referenzen, nichts wird gelöscht). „Ignorieren" merkt sich die Gruppe und nervt nicht erneut. Löschen eines Sets fragt nach und stellt betroffene Verbindungen auf „Manuell" mit kopierten Werten zurück — nie kaputte Verbindungen.

Verbindungsformular: neben dem Login-Picker ein kleiner Link „Logins verwalten…" (öffnet das Logins-Sheet).
TOFU-Prompt: Fußnote „Bekannte Hosts verwalten…" (öffnet das Known-Hosts-Sheet — z. B. um einen rotierten Key zu entfernen).

Vorschlag: EIN neues Menü „Sessions" in der Menüleiste bündelt alles Verwaltende (Logins ⌘⇧L, Bekannte Hosts ⌘⇧K, Import/Export — die heute schon existierenden Export/Import-Einträge des Sidebar-Menüs erscheinen dort zusätzlich). Dieselben zwei Einträge auch im Sidebar-Hintergrund-Rechtsklick (kurzer Weg, wo man ohnehin Sessions verwaltet). Dazu zwei Kontext-Einstiege an den Stellen, wo man sie wirklich braucht (Formular → Logins; TOFU-Prompt → Known Hosts). Beide Bereiche öffnen als Sheets im Hauptfenster — kein neues Fenster, kein Settings-Umbau (die Settings bleiben App-Verhalten: Allgemein/Transfers/Öffnen mit).
